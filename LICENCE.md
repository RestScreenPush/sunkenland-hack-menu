## 🧩 About

**Sunkenland overlay** is a curated list of Sunkenland open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, map viewer
- **Quality-of-Life Helpers** — inventory notes, crafting helper, base layout planner
- **Research Notes** — survival strategies and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Resource Tracker — monitor nearby materials and loot
- Map Overlay — visualize islands and points of interest
- Crafting Helper — quick reference for recipes
- Base Planner — layout notes for efficient builds

### 🎨 Interface & HUD
- Custom HUD — configurable on-screen info
- Inventory Sorter — organize items with one click
- Compass Overlay — directional aid for exploration
- Status Bars — health, hunger, oxygen at a glance

### 🏋️ Exploration Aids
- Waypoint System — mark and return to locations
- Depth Gauge — monitor underwater time
- Enemy overlay — track hostile creatures nearby
- Weather Indicator — plan dives around storms

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
